
CHANGELOG | FANCYMENU v3.10.0 [ W I P !! Not public yet !! ]

- Added Ukrainian translation (#1817)
- Added volume and sound channel settings for the open and close audio of screens (#1603)
- Added volume and sound channel settings for click sounds of buttons, sliders, checkboxes, input fields and vanilla widgets (#1603)
- Added volume and sound channel settings for hover and unhover sounds of buttons, sliders, checkboxes, input fields and vanilla widgets
- Added volume and sound channel settings for the global custom button click sound
- Sound channel names in layouts, actions and settings are now recognized no matter how they are capitalized
- Added "On Start Joining Server" listener, which triggers as soon as you start connecting to a server or Realm, even when the connection fails, and gives you the server's IP as `$$server_ip` (#1738)
- Added the "Keybind Key" placeholder, which shows the key currently bound to a keybind (like "Space" for "key.jump") (#1676)
- Added a Light Count option to every string of the String Lights overlay, to set an exact number of lights or let it fill automatically (#1563)
- Added a String Color option to every string of the String Lights overlay, with alpha support to make the string see-through or hide it (#1563)
- Added Individual Light Sizes to every string of the String Lights overlay, to give each light its own size or hide single lights (#1563)
- Added Individual Light Colors to every string of the String Lights overlay, to give each light its own color (#1563)
- Added a new "Delete Variable" action that completely removes a single variable while keeping all other variables untouched (#1737)
- Added the "On File Download Started via Action" listener, which triggers when the "Download File to Game Directory" action starts downloading a file and gives you the download URL and the target file path (#1765)
- Added a "Text Height" placeholder that returns the height of a text in pixels, counting every line (#1803)
- Added a "Text Element Content Height" placeholder that returns the height a Text element needs to show all of its text, so backgrounds and other elements can automatically fit it (#1803)
- Added a new "On Screenshot Taken" listener that triggers whenever you take a screenshot and gives you the screenshot's path inside your instance folder as a variable (#1773)
- Added an "Achievement Toasts" option to Global Customizations to turn the popups for unlocked achievements on or off (on by default) (#1663)
- Added "On Achievement Unlocked" listener that triggers when you unlock an achievement, with variables for the achievement's key, title, description, icon item and type (advancement, goal or challenge) (#1662)
- Added input fields for the red, green, blue and alpha values to the color picker, so you can type exact RGBA values (#1652)
- Added the newest texts (browser loading/error messages and the "select an action first" warning) to all other translations
- Added placeholder support to the Custom Window Title, so it can show things like your modpack version, the Minecraft version or variables (#1764)
- Improved the description of the "Negate Number" placeholder in all languages
- Improved performance of video elements and video menu backgrounds that play local files with Rinku (the file is no longer re-checked on disk every frame)
- The Pause screen's World Options button (Multiplayer Options in MC 26.2) now has a stable widget ID, so "Mimic Button" actions and layout customizations keep finding it even when other mods shift the menu (#1825)
- Updated outdated texts in all translations so they match the current English descriptions (Delay Gate block, browser mute option, mouse button requirement, file and resource security notes, shader opacity and more)
- The "Open to LAN" and "Report Player" buttons of the pause screen can now be customized separately (#1730)
- Layouts made before this change still give the "Report Player" button the "Open to LAN" button's customizations, so they look the same as before (#1730)
- Fixed undo not bringing back the old value after changing a setting with a slider, number picker or color picker in the layout editor
- Fixed "On Server Joined" and "On Server Left" actions crashing the game when they triggered their own listener again, like a disconnect action in "On Server Left"
- Fixed the layout editor deleting the customizations of vanilla buttons that only show up in singleplayer or only in multiplayer when saving a layout in the other mode (#1730)
- Fixed some Russian and Polish opacity settings being labeled as "transparency"
- Fixed inconsistent shader terms in the Spanish (Mexico) translation
- Fixed stray foreign-language words in two Korean texts
- Fixed the "Open Screen" action failing to open the "Open to LAN" and World Options screens (#1825)
- Fixed Browser element, Browser menu background and Browser decoration overlay URLs breaking when they contain placeholders, because `&` parameters like `&embed` or `&f` were treated as Minecraft formatting codes (#1818)
- Fixed image, audio, video and text sources, video elements and backgrounds, player skin and cape sources and the game intro breaking when their source contains placeholders and an `&` followed by a letter or number, like `&embed` (#1818)
- Fixed file actions, the Send HTTP Request action, remote server actions, the Play Audio action and the Enter World action breaking when their value contains placeholders and an `&` followed by a letter or number (#1818)
- Fixed the Open Link action turning `§` characters in links into `&` (#1818)
- Fixed `/fmlayout` error messages showing "%s" instead of the layout name
- Fixed typos in several English texts (boss name and boss health placeholders, experience progress placeholder, async requirement error, welcome screen title)
- Fixed the "Video Background Paused State" placeholder description talking about an element instead of a background
- Fixed local images, videos, file placeholders and file actions failing when the FancyMenu config folder (or `fancymenu_data`) is moved elsewhere and replaced with a symbolic link or junction (#1812)
- Fixed the game crashing during startup on Minecraft 26.3 when FancyMenu elements are shown on the loading screen, for example in Drippy Loading Screen layouts (#1826)
- Fixed the game crashing on the Vulkan renderer when FancyMenu elements are shown on the initial loading screen (#1826)
- Fixed rounded shapes, images and panoramas being invisible on the initial loading screen until the game finished loading (#1826)
- Fixed blurred elements on the initial loading screen resetting the selected resource packs or crashing the game (#1826)
- Fixed the game crashing on startup with NeoForge when the loading screen window was resized (#1820)
- Fixed the game freezing on the loading screen during startup, which could leave the old smaller frame in the top-left corner with black around it when the game switched to fullscreen (#1815)
- Fixed the "Multiplayer Screen Server Icons" setting not hiding server icons on MC 26.1.2 (#1819)
- Fixed vanilla buttons and player entities not rendering when a GLSL shader is used as menu background (#1827)
- Fixed customizations of buttons that other mods add next to the Realms button on the Title screen (like the Flashback button) not getting applied outside the layout editor (#1748)
- Fixed a crash with OneConfig and other mods that render items into their own offscreen GUI, and fixed those mods' content being cut off or wrongly scaled (#1821)
- Fixed GLSL shaders being drawn too small and in the wrong place, and getting wrong mouse coordinates, when a custom (non-whole-number) GUI scale is active
- Fixed GLSL shaders not rendering on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
- Fixed GLSL shader channel textures and video background thumbnails not working on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
- Fixed WaterMedia videos crashing the game on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
- Added a confirmation dialog to "Reload Minecraft Resources" in the customization menu bar, so a misclick no longer starts a full resource reload (#1574)
- Fixed the confirmation dialog of "Disable Customization for ALL Screens" being hidden behind the open customization menu
- Fixed pressing Enter in the color picker closing it without saving an undo step for the new color
