
CHANGELOG | FANCYMENU v3.11.0 [ W I P !! Not public yet !! ]






- Added the "Scrollable Area" element, a container that holds other elements, scrolls them vertically, horizontally or both, and cuts them to its size
  - Place elements freely with anchors, or let the area arrange them automatically (Stack, Grid, Flow)
  - Scrolling options: scroll speed, smooth scrolling, drag-to-scroll, snapping to elements or pages, auto-scrolling, start position, keyboard scrolling and following the focused element
  - Customizable scroll bars (grabber styles, bar backgrounds, thickness, side, visibility) and a background
  - Drag elements into and out of areas in the layout editor, and resize the content with a handle
  - Anchor points of elements in an area sit at the edges and the middle of its whole content and scroll with it
  - Areas scroll on their own while you drag elements close to their edges, and dragged elements stay under the mouse while the area scrolls
  - Nested layers in the layer list, and copying, pasting or deleting an area with everything in it
  - An action to scroll areas, placeholders for their scroll position and content size, a requirement for areas scrolled to their end, and listeners for scrolled content
- Completely reworked the Decoration Overlays
  - Existing overlays got a new look: Snow, Rain, Confetti, Fireworks, String Lights, Fireflies and Leaves
  - Added 15 new decoration overlays: Cherry Blossoms, Shooting Stars, Aurora, Clouds, Fog, Sunbeams, Butterflies, Birds, Bats, Bubbles, Sky Lanterns, Overgrowth, Frost, Cobwebs and Embers
  - Decoration overlays can now draw behind elements, so far snow, rain, clouds, the aurora and more pass behind buttons and the title
  - Added a "Layers" setting to all decoration overlays to draw them in the background, the foreground or both
  - Added a Detailed and a Simple look to String Lights, Fireflies, Leaves and Cherry Blossoms
  - Added a Pine Garland option and a Light Program option to String Lights
  - Added an Unlit Bodies option to Fireflies
  - Added an Autumn Mix or Custom Range color choice to Leaves
  - Added Amount and Size options to the decoration overlays
- Completely reworked the Markdown renderer used for both the Text element and the Tooltip element
  - Added three Markdown looks to choose from: Pixel (new pixel art style), Classic (the previous look) and Neutral (follows the UI theme)
    - New Text and Tooltip elements now use the Pixel look by default, while existing layouts keep their old look
  - Added changelog-style list markers: `+` for added, `-` for removed, `~` for changed and `*` for highlighted things
  - Added numbered lists
  - Added callouts (`> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`)
  - Added strikethrough text support (`~~text~~`)
  - Added bold text via double underscores (`__text__`)
  - Added a fixed-width pixel font for code and an option to set a custom code font
  - Added captions for images, taken from their alternative text
  - Markdown text in languages without spaces between words, like Chinese and Japanese, now wraps correctly
  - Code blocks now accept a language name behind their opening marker
  - Link targets can now contain pairs of round brackets
  - The Markdown renderer now has much better performance, especially with long texts, tables and scrolling
  - Reworked the Markdown config menu of Text and Tooltip elements with around 150 style options for text, headlines, lists, links, code, quotes, callouts, tables, images and separators
- Completely reworked APNG textures with FancyMenu's own APNG decoder and renderer, so APNGs now barely use any memory while playing with great performance, which puts them on the same level as AFMA (or even above it) and makes them a great choice for animated content
  - No longer needs WaterMedia or any other library to play APNGs
  - Supports every APNG and PNG feature, including interlaced images, all color types and bit depths, transparency and all frame blend and dispose modes
  - Decodes frames in the background, a few frames ahead, and only updates the parts of the image that change between frames
  - Big APNGs (like 1080p menu backgrounds) play smoothly at their full frame rate
  - Frame data gets read from disk while playing instead of being kept in memory, so even huge APNG files take almost no RAM
  - Local APNG files can be renamed or deleted while they play, and an APNG whose file gets replaced while playing stops cleanly on its last frame
  - Restarting an APNG (like on menu load or button hover) shows its first frame instantly
  - Pausing and resuming APNGs (like button backgrounds that only play while hovered) continues right where they stopped
  - APNGs that play a limited number of times now stop on their last frame
  - Broken or partly downloaded APNGs play all intact frames instead of failing completely
- GIFs got the same treatment as APNGs and now use FancyMenu's own GIF decoder and renderer, so they also barely use any memory while playing with great performance
  - No longer needs WaterMedia or any other library to play GIFs
  - Supports every GIF feature, including transparency, interlaced GIFs, per-frame color palettes, loop counts and all frame dispose modes
  - Plays GIFs just like web browsers do, including frame timing and how often they loop
  - Decodes frames in the background, a few frames ahead, and only updates the parts of the image that change between frames
  - Big GIFs (like 1080p menu backgrounds) play smoothly at their full frame rate
  - Frame data gets read from disk while playing instead of being kept in memory, so even huge GIF files take almost no RAM
  - Local GIF files can be renamed or deleted while they play, and a GIF whose file gets replaced while playing stops cleanly on its last frame
  - Restarting a GIF (like on menu load or button hover) shows its first frame instantly
  - Pausing and resuming GIFs (like button backgrounds that only play while hovered) continues right where they stopped
  - GIFs that play a limited number of times now stop on their last frame
  - Broken or partly downloaded GIFs play all intact frames instead of failing completely
- Added formatting shortcuts to the text editor of Text and Tooltip element content (#1644)
  - Ctrl + B, Ctrl + I and Ctrl + U make the selected text bold, italic or underlined, and pressing them again removes the format
  - Without a selection, they add the format markers and put the cursor between them, so you can just keep typing
  - Ctrl + L, Ctrl + E and Ctrl + R align the selected lines (or the line of the cursor) left, centered or right
  - Pressing Ctrl + E or Ctrl + R on lines that already have that alignment aligns them left again
  - Uses Cmd instead of Ctrl on macOS
  - Doesn't get in the way when typing characters with AltGr, like € or ł
  - New "Formatting" menu in the right-click menu of the editor that shows all formatting actions and their shortcuts
- Added list variables, so variables can hold a list of entries instead of just one text value (#1870)
  - Variables can be text or list variables, and Manage Variables can create both
  - Lists work everywhere text variables work, like `$$name`, the Get Variable placeholder, the Is Variable Value requirement and listeners
  - Existing variables load unchanged, and text variables never turn into lists on their own
  - New actions to work with lists: Add to List, Set List Entry, Remove from List, Clear List, Set List and Arrange List (sort, sort numbers, reverse, shuffle, remove duplicates)
  - Readable summaries of list action values in the action script editor
  - New placeholders: List Get, List Size, List Index Of and List Join
  - New List Contains Entry requirement
  - New FOR EACH loop block for action scripts that runs its contents once for every list entry, with `$$list_entry` and `$$list_index`, also in nested loops
  - Indexes start at 0, and negative indexes count from the end
  - Edit List window with inline editing, drag and drop, undo/redo, search and "Edit as Text"
  - List previews in Manage Variables and converting variables between text and list
  - Slider elements can take their values from a list variable and follow its changes live
  - Input fields and checkboxes linked to a list variable keep working
  - Lists in the AI export, and GLSL variable uniforms of lists give their entry count
