
CHANGELOG | FANCYMENU v3.10.0 [ W I P !! Not public yet !! ]

- Added Ukrainian translation (#1817)
- Added support for the latest WaterMedia (v3.0.1) and WaterMedia Binaries (v3.0.1)
  - FancyMenu now needs WaterMedia 3.0.1+, older versions will not work anymore!
- Added Profiles, which save your whole FancyMenu setup so you can switch between setups at any time (Customization → Profiles)
  - Profiles can have a title, version, authors, a Markdown description, an issue tracker link, social links and a 64x64 icon
  - Loading a profile fully reloads FancyMenu, just like starting the game fresh
  - Your current setup is saved to its own profile automatically when you load another one, so nothing gets lost
  - Profiles can be shared as .fmp files, and importing one is as easy as dropping it onto the Profiles window
  - Imports warn you when a profile was made with a newer FancyMenu version, and let you replace or keep both when you already have that profile
  - New empty profiles keep your personal FancyMenu UI settings, so you don't see the welcome screen or lose your UI preferences
- Added "Is Block/Item In Tag" requirement to check if a block or item is part of a tag like #minecraft:logs or #c:tools, which also works with listener variables like $$block_key (#1829)
- Added a confirmation popup to the "Join the Discord" button in the menu bar, explaining that the server is for Keksuccino's mods and not for the modpack you're playing
- Added an "Ignore Game Intro Loops" option to the Game Intro settings (enabled by default), so looping GIF, APNG, FMA and AFMA intros end after playing through once (#1650)
- Added the "Total Active Raid Waves", "Remaining Active Raid Waves", "Current Active Raid Wave", "Active Raid Alive Raiders Count" and "Active Raid Alive Raiders List" placeholders (#1701)
- Added the "On Raid Started", "On Enter Active Raid Area", "On Leave Active Raid Area" and "On Raid Finished" listeners, with "On Raid Finished" telling you whether the raid ended in a victory or a defeat (#1701)
- Added the "Is In Active Raid Area" requirement (#1701)
- Added enabled/disabled indicators to the background types in the layout editor's background menu, so you can see at a glance which backgrounds are active (#1607)
- Added enabled/disabled indicators to the decoration overlay types in the layout editor's overlay menu, so you can see at a glance which overlays are active (#1608)
- Added volume and sound channel settings for the open and close audio of screens (#1603)
- Added volume and sound channel settings for click sounds of buttons, sliders, checkboxes, input fields and vanilla widgets (#1603)
- Added volume and sound channel settings for hover and unhover sounds of buttons, sliders, checkboxes, input fields and vanilla widgets
- Added volume and sound channel settings for the global custom button click sound
- Sound channel names in layouts, actions and settings are now recognized no matter how they are capitalized
- Added "On Start Joining Server" listener, which triggers as soon as you start connecting to a server or Realm, even when the connection fails, and gives you the server's IP as `$$server_ip` (#1738)
- Added the "Keybind Key" placeholder, which shows the key currently bound to a keybind (like "Space" for "key.jump") (#1676)
- Added a Light Count option to every string of the String Lights overlay, to set an exact number of lights or let it fill automatically (#1563)
- Added a String Color option to every string of the String Lights overlay, with alpha support to make the string see-through or hide it (#1563)
- Added Individual Light Sizes to every string of the String Lights overlay, to give each light its own size or hide single lights (#1563)
- Added Individual Light Colors to every string of the String Lights overlay, to give each light its own color (#1563)
- Added a new "Delete Variable" action that completely removes a single variable while keeping all other variables untouched (#1737)
- Added the "On File Download Started via Action" listener, which triggers when the "Download File to Game Directory" action starts downloading a file and gives you the download URL and the target file path (#1765)
- Added a "Text Height" placeholder that returns the height of a text in pixels, counting every line (#1803)
- Added a "Text Element Content Height" placeholder that returns the height a Text element needs to show all of its text, so backgrounds and other elements can automatically fit it (#1803)
- Added a new "On Screenshot Taken" listener that triggers whenever you take a screenshot and gives you the screenshot's path inside your instance folder as a variable (#1773)
- Added an "Achievement Toasts" option to Global Customizations to turn the popups for unlocked achievements on or off (on by default) (#1663)
- Added "On Achievement Unlocked" listener that triggers when you unlock an achievement, with variables for the achievement's key, title, description, icon item and type (advancement, goal or challenge) (#1662)
- Added input fields for the red, green, blue and alpha values to the color picker, so you can type exact RGBA values (#1652)
- Added the newest texts (browser loading/error messages and the "select an action first" warning) to all other translations
- Added placeholder support to the Custom Window Title, so it can show things like your modpack version, the Minecraft version or variables (#1764)
- Added color emoji support to FancyMenu's UI text, including flags, skin tones and combined emoji like 👨‍👩‍👧
- Added a confirmation dialog to "Reload Minecraft Resources" in the customization menu bar, so a misclick no longer starts a full resource reload (#1574)
- Improved FancyMenu's UI text so it looks much sharper at every GUI and UI scale, including scaled text
- Improved letter spacing of FancyMenu's UI text by adding kerning
- Improved performance of FancyMenu's UI text rendering, text measuring and line wrapping, and reduced its GPU memory use
- Improved loading of Japanese, Korean and Chinese FancyMenu UI fonts, which now only load when text needs them
- Improved line wrapping in FancyMenu's UI so it no longer splits emoji
- Improved the description of the "Negate Number" placeholder in all languages
- Improved performance of video elements and video menu backgrounds that play local files with Rinku (the file is no longer re-checked on disk every frame)
- The Pause screen's World Options button (Multiplayer Options in MC 26.2) now has a stable widget ID, so "Mimic Button" actions and layout customizations keep finding it even when other mods shift the menu (#1825)
- Updated outdated texts in all translations so they match the current English descriptions (Delay Gate block, browser mute option, mouse button requirement, file and resource security notes, shader opacity and more)
- The "Open to LAN" and "Report Player" buttons of the pause screen can now be customized separately (#1730)
- Layouts made before this change still give the "Report Player" button the "Open to LAN" button's customizations, so they look the same as before (#1730)
- Video intros now always end after one playthrough, even if a looping video background uses the same video (#1650)
- Wakes is no longer marked as incompatible on MC 1.21.11, and on newer versions only Wakes versions older than 0.7.3 are still blocked, since Wakes fixed the crash on its end (#1830)
- The Mods button in the Title screen now has the same identifier (`titlescreen_mods_button`) on Fabric (Mod Menu), Forge and NeoForge, so customizing it on one loader also works on the others
  - Old layouts that customized the Mods button with its old Forge/NeoForge or Mod Menu identifier get converted to the new identifier automatically when loaded
  - Element anchors, actions, requirements and placeholders that still use one of the old Mods button identifiers keep working
- Reworked UI and element blur so it looks smoother and costs far less GPU time and video memory
- Blur strength now looks the same at every GUI scale and screen resolution
- The UI blur intensity slider now works across its whole range
- Blur memory is freed automatically when nothing has used blur for a few seconds

- Custom GUI popup backgrounds now follow Minecraft's "Menu Background Blur" accessibility option (1.21.1 and newer)
- Toggles with an Enabled/Disabled/Manual state now show the state of the whole selection when multiple elements are selected, and one click on a mixed selection enables all of them (#1831)
