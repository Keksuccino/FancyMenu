
CHANGELOG | FANCYMENU v3.9.15 [ W I P !! Not public yet !! ]

- Added Ukrainian translation (#1817)
- Added the newest texts (browser loading/error messages and the "select an action first" warning) to all other translations
- Improved the description of the "Negate Number" placeholder in all languages
- Improved performance of video elements and video menu backgrounds that play local files with Rinku (the file is no longer re-checked on disk every frame)
- The Pause screen's World Options button (Multiplayer Options in MC 26.2) now has a stable widget ID, so "Mimic Button" actions and layout customizations keep finding it even when other mods shift the menu (#1825)
- Fixed the "Open Screen" action failing to open the "Open to LAN" and World Options screens (#1825)
- Fixed Browser element, Browser menu background and Browser decoration overlay URLs breaking when they contain placeholders, because `&` parameters like `&embed` or `&f` were treated as Minecraft formatting codes (#1818)
- Fixed image, audio, video and text sources, video elements and backgrounds, player skin and cape sources and the game intro breaking when their source contains placeholders and an `&` followed by a letter or number, like `&embed` (#1818)
- Fixed file actions, the Send HTTP Request action, remote server actions, the Play Audio action and the Enter World action breaking when their value contains placeholders and an `&` followed by a letter or number (#1818)
- Fixed the Open Link action turning `§` characters in links into `&` (#1818)
- Fixed `/fmlayout` error messages showing "%s" instead of the layout name
- Fixed typos in several English texts (boss name and boss health placeholders, experience progress placeholder, async requirement error, welcome screen title)
- Fixed the "Video Background Paused State" placeholder description talking about an element instead of a background
- Fixed local images, videos, file placeholders and file actions failing when the FancyMenu config folder (or `fancymenu_data`) is moved elsewhere and replaced with a symbolic link or junction (#1812)
- Fixed the game crashing during startup on Minecraft 26.3 when FancyMenu elements are shown on the loading screen, for example in Drippy Loading Screen layouts (#1826)
- Fixed the game crashing on the Vulkan renderer when FancyMenu elements are shown on the initial loading screen (#1826)
- Fixed rounded shapes, images and panoramas being invisible on the initial loading screen until the game finished loading (#1826)
- Fixed blurred elements on the initial loading screen resetting the selected resource packs or crashing the game (#1826)
- Fixed the game crashing on startup with NeoForge when the loading screen window was resized (#1820)
- Fixed the game freezing on the loading screen during startup, which could leave the old smaller frame in the top-left corner with black around it when the game switched to fullscreen (#1815)
- Fixed the "Multiplayer Screen Server Icons" setting not hiding server icons on MC 26.1.2 (#1819)
- Fixed vanilla buttons and player entities not rendering when a GLSL shader is used as menu background (#1827)
- Fixed customizations of buttons that other mods add next to the Realms button on the Title screen (like the Flashback button) not getting applied outside the layout editor (#1748)
- Fixed a crash with OneConfig and other mods that render items into their own offscreen GUI, and fixed those mods' content being cut off or wrongly scaled (#1821)
- Fixed GLSL shaders being drawn too small and in the wrong place, and getting wrong mouse coordinates, when a custom (non-whole-number) GUI scale is active
- Fixed GLSL shaders not rendering on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
- Fixed GLSL shader channel textures and video background thumbnails not working on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
- Fixed WaterMedia videos crashing the game on NeoForge 1.21.11 when NeoForge's Blaze3D validation layer is enabled
