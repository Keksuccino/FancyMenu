
CHANGELOG | FANCYMENU v3.11.0 [ W I P !! Not public yet !! ]

- Added the "Scrollable Area" element, a container that holds other elements, scrolls them vertically, horizontally or both, and cuts them to its size
  - Place elements freely with anchors, or let the area arrange them automatically (Stack, Grid, Flow)
  - Scrolling options: scroll speed, smooth scrolling, drag-to-scroll, snapping to elements or pages, auto-scrolling, start position, keyboard scrolling and following the focused element
  - Customizable scroll bars (grabber styles, bar backgrounds, thickness, side, visibility) and a background
  - Drag elements into and out of areas in the layout editor, and resize the content with a handle
  - Anchor points of elements in an area sit at the edges and the middle of its whole content and scroll with it
  - Areas scroll on their own while you drag elements close to their edges, and dragged elements stay under the mouse while the area scrolls
  - Nested layers in the layer list, and copying, pasting or deleting an area with everything in it
  - An action to scroll areas, placeholders for their scroll position and content size, a requirement for areas scrolled to their end, and listeners for scrolled content
- Completely reworked the Decoration Overlays
  - Existing overlays got a new look: Snow, Rain, Confetti, Fireworks, String Lights, Fireflies and Leaves
  - Added 15 new decoration overlays: Cherry Blossoms, Shooting Stars, Aurora, Clouds, Fog, Sunbeams, Butterflies, Birds, Bats, Bubbles, Sky Lanterns, Overgrowth, Frost, Cobwebs and Embers
  - Decoration overlays can now draw behind elements, so far snow, rain, clouds, the aurora and more pass behind buttons and the title
  - Added a "Layers" setting to all decoration overlays to draw them in the background, the foreground or both
  - Decorations that sit on elements, like snow caps, frost, moss or resting birds, always stay on their element
  - Added a Detailed and a Simple look to String Lights, Fireflies, Leaves and Cherry Blossoms
  - Added a Pine Garland option and a Light Program option to String Lights
  - Added an Unlit Bodies option to Fireflies
  - Added an Autumn Mix or Custom Range color choice to Leaves
  - Added Amount and Size options to the decoration overlays
- Completely reworked the Markdown renderer used for both the Text element and the Tooltip element
  - Added three Markdown looks to choose from: Pixel (new pixel art style), Classic (the previous look) and Neutral (follows the UI theme)
    - New Text and Tooltip elements now use the Pixel look by default, while existing layouts keep their old look
  - Added changelog-style list markers: `+` for added, `-` for removed, `~` for changed and `*` for highlighted things
  - Added numbered lists
  - Added callouts (`> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`)
  - Added strikethrough text support (`~~text~~`)
  - Added bold text via double underscores (`__text__`)
  - Added a fixed-width pixel font for code and an option to set a custom code font
  - Added captions for images, taken from their alternative text
  - Markdown text in languages without spaces between words, like Chinese and Japanese, now wraps correctly
  - Code blocks now accept a language name behind their opening marker
  - Link targets can now contain pairs of round brackets
  - The Markdown renderer now has much better performance, especially with long texts, tables and scrolling
  - Reworked the Markdown config menu of Text and Tooltip elements with around 150 style options for text, headlines, lists, links, code, quotes, callouts, tables, images and separators
- Added a Label Alignment option (Left, Centered or Right) to custom buttons and sliders, and to vanilla buttons and sliders (#1866)
- Added label alignment settings for buttons and sliders to Global Customizations (#1866)
- Added a background to the Text element, with a built-in pixel art panel, custom texture support, nine-slice settings, padding and an option to render behind the scroll bars
- Added a pixel art scroll grabber style to the Text element
- Added "Export for AI" to many parts of FancyMenu, which copies or saves your setup (variables, listeners, schedulers, action scripts, layouts, elements, screens, settings, system info and more) as English text made for AI assistants like Alice, the support bot on Keksuccino's Discord
- Added `/fmdata export_for_ai copy|file` to export the server's FMData listeners and welcome data for AI
- Added a "Preserve Background Texture Aspect Ratio" toggle for the global custom menu background texture, so you can choose between stretching it to fill the screen and keeping its original proportions
- Added smooth scrolling, a scroll speed setting, sideways and Shift + mouse wheel scrolling, drag scrolling and keyboard scrolling (Page Up/Down, Home, End) to the Text element
- Added nine-sliced backgrounds behind the scroll bars of Text elements
- Added a scroll direction setting (vertical, horizontal or both) to the Text element
- Added auto-scroll to the Text element, with speed, loop and pause-on-hover settings
- Added scroll snapping to the Text element (to lines, to Markdown headlines or to pages)
- Added a scroll start position setting (start or end) to the Text element
- The Text element now remembers its scroll position across resizes and reopening, with a "reset on open" toggle
- Added scroll bar settings to the Text element: visibility (always, while scrolling, never), thickness, vertical bar on the left and horizontal bar at the top
- Placeholders are now replaced much faster, especially in long texts and texts with many placeholders, so big texts no longer cause lag
- Texts can now have up to 100,000 characters for their placeholders to get replaced (was 17,000)
- The "text too long" error is now translated into all supported languages
- Every Random Number placeholder in a text now gets its own number, also when the same placeholder appears multiple times
- NBT Data placeholders with random entity selectors like `@r` now pick a new entity for every copy in a text
- `$$variable` references, Slider labels and element values now resolve faster when there are many variables
- Message dialogs now grow to fit their message, and very long messages get a scroll bar
- Message dialog buttons now shrink to fit in small game windows instead of getting cut off
- Scroll grabbers of the Text element now fade with the opacity of the element
