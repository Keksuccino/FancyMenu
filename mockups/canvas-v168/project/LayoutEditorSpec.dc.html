FancyMenu · UI rework concept · layout editor

Edit the screen like in a design tool

The layout editor becomes a canvas editor. The screen sits on an artboard you can zoom, with rulers, smart guides and previews for other screen sizes. Layers and a new Inspector dock beside the screen instead of covering it, and the Element Animator turns into a timeline under the canvas. Settings that took a right-click, a submenu and a window are one click away now.

Animations

  • Animations belong to the layout, not to an extra element. A layout can have several, like Intro and Idle, picked from the menu at the left of the timeline.
  • An animation has a track per element, with a row per animated property: Position, Size, Rotation, Vertical Tilt, Horizontal Tilt and Opacity. Only properties with keyframes animate, so an element can fade without moving. Every animatable row in the Inspector has its keyframe diamond.
  • Every keyframe has its own easing, for the stretch that ends at it: Linear, Ease In, Ease Out, Ease In and Out, Overshoot, Hold, or a custom curve with two handles. Positions move in fractions of a GUI pixel, rounded to real screen pixels, so motion is smooth and pixel art stays sharp. Clicks and layout keep using whole pixels.
  • Values are offsets from the element's resting position by default, so an animation that ends at rest ends exactly where the element sits, at any screen size. With Move From Resting Position off, every keyframe keeps its own anchor and position, like today's keyframes. At the End holds the last keyframe or snaps back to rest.
  • An animation plays when the screen opens, or when an action starts it, and Plays Only When adds conditions. It can wait a start delay, loop, and reverse every other loop. Its length is set by dragging the end marker on the ruler, or in the Inspector.
  • Animated opacity multiplies with the element's own opacity and fades. Stay On Screen only holds the resting position, so elements can slide in from outside the screen. Elements anchored to an animated element follow its position.
  • Keyframes get added with the diamond next to a property, in the timeline or in the Inspector, with K, or by themselves with Auto-Key while you move or change elements. There is no recording mode anymore.
  • While the timeline is open, the canvas and the Inspector show the screen at the playhead, and animated values show in amber. Dragging on the ruler scrubs, clicking it jumps. Keyframes can be box-selected, dragged, copied and pasted, and snap to each other and to the playhead. Space Evenly in their right-click menu spreads them out, like Distance Smoothing today. Play runs the animation once, like in game, unless it loops; Repeat Playback in the timeline keeps it going while you work.
  • Deleting an element deletes its tracks in the same undo step, and copies of an element take their tracks along.
  • Element Animators turn into layout animations when a layout opens, in memory only. The file changes when you save, after a backup of the original. Each animation keeps the animator's ID, so the four animator actions, the saved play state and the animator's loading conditions keep working. Targets keep their per-keyframe anchors, timing offsets become a start offset per track, random ones stay random, and At the End is Snap Back, like today. Targets in other layouts show as greyed tracks.

On macOS every Ctrl is Cmd, and menus and tooltips say so, with the key names of your keyboard layout. Every shortcut works without AltGr, and Ctrl+Y still redoes, like today. Ctrl+G used to show the grid; the grid moves to Shift+G so Group gets the shortcut every editor uses.

Keys go to what you clicked last: the canvas, a panel or a field. Text fields keep their own keys, and single letters only work on the canvas, so typing to search a menu never triggers them. Tab hides the panels only while the canvas has the keyboard; everywhere else it moves focus, like always. Esc closes a popover, then leaves a field, then stops Preview, then selects none.

Behavior

  • Selecting on the canvas, in Layers or in the timeline selects in all three. Layers opens the group the selection is in and scrolls to it.
  • The Inspector shows the selection's settings. With several elements selected it shows the settings they share, Mixed where they differ. With nothing selected it shows the layout's settings, and with a keyframe selected, the keyframe's.
  • Search in the Inspector filters every section at once, by setting name or section name.
  • Double-clicking plain text without rotation or tilt edits it right on the canvas; other text opens the text editor. Double-clicking a layer or the Inspector header, or F2, renames in place.
  • With a placeholder in X or Y, that axis becomes an absolute screen position: the field says so, shows the resolved value, and dragging stops moving that axis. With Auto-Sizing or Stretch, W and H show the size it resolves to.
  • Anchoring to an element measures from its top-left corner. Deleting an element offers to keep the elements anchored to it where they are. Moving several elements skips the ones whose anchor element moves along.
  • Vanilla widgets can't be cut, duplicated, grouped or restacked, so those rows are greyed out for them. Dragging one off its original position gives it the nearest screen anchor.
  • Dropping image, sound or video files onto the canvas copies them into the assets folder and adds them where they land. A file with a taken name gets a number. The hint in the status bar is always there, since Minecraft can't tell when files are dragged over it.
  • Locked elements can't be picked or moved on the canvas, only selected in Layers. Hidden elements stay hidden in the editor only. Both are saved with the layout and can be undone, like hiding is today. For vanilla widgets the eye in Layers hides them in game instead, since that's the only way they can be hidden.
  • Zoom, the playhead, Screen Size, Auto-Key and the panels are never undo steps and never make the layout unsaved. Undo rebuilds only the elements that changed, so videos and sounds keep playing. Settings that reopen the screen, like Force GUI Scale, apply when the slider is let go.
  • Non-modal windows belong to their element and close if it goes away. Cancel undoes only that window's changes.
  • Elements that draw nothing, like audio, tickers and cursors, show as labeled boxes on the canvas, red when something they need is missing.
  • The Problems item in the status bar lists missing files, broken anchors, deprecated elements, elements outside the screen at the chosen screen size and placeholders that don't resolve. Clicking a problem selects its element.
  • Rows a Custom GUI sets in its own settings, like Screen Title, are greyed out and link there.
  • In small windows, like Minecraft's default 854 × 480, Layers turns into a popover from the toolbar, the Inspector slides over the canvas edge, and the timeline caps its height, so the canvas keeps most of the window.
  • The editor stays how you left it, even after restarting the game. Which panels are shown, their sizes and where they dock, folded Inspector sections and timeline tracks, the View settings like grid, rulers and snapping, and the zoom of each layout are saved for you in FancyMenu's config, never in the layout file. Tab and Preview always start off, and a layout opens fit to the window the first time.

Under the hood

  • The artboard is the real screen drawn into an offscreen target at the previewed window size and GUI scale, then shown zoomed, with sharp pixels at whole zoom levels. Pointer input maps back through the same transform, so models, entities and scissor areas look exactly like in game.
  • Elements read the screen size and GUI scale from a virtual window instead of the real one, which is what makes Screen Size work. Vanilla widgets come from running the screen's init at that size.
  • Preview runs on its own runtime layer, with separate element memory. Variables get restored afterwards, schedulers stop, and presses on vanilla widgets are swallowed, so nothing carries over to the real menu.
  • Docking is new: panels dock to the window edges with draggable splits, and float when dragged out by their header.
