FancyMenu · UI rework concept · color picker

Pick, type or sample any color

The color picker keeps its job and its live preview, but every color format can now be typed into: Hex, RGBA and HSV stay in sync while you edit any of them. The window names the color it edits, compares it with the original in one swatch, and adds an eyedropper and recent colors for the colors you use again and again.

Behavior

  • Every change shows on the element right away. Cancel, the red traffic light and Esc put the original color back; Done or Enter keeps the new one as one undo step.
  • Dragging keeps working when the pointer leaves the square or a slider, so small or fast moves never get cut off.
  • Text that is not a valid value yet stays in the field and turns the field red, instead of being replaced while you type. Leaving the field shows the current value again.
  • Arrow keys nudge the selected handle by 1 step, Shift+arrow by 10.
  • The window can be resized: the square grows with it, the right column keeps its width.
