FancyMenu · UI rework concept · Pre-Load Resources

Ready the moment a menu opens

Pre-loading loads big resources while the game starts, so menus don't wait for them. The window now shows each resource with a preview, how long it took at the last game start and where it's used, and flags the ones that failed or held the start up. Added resources load right away, and the game start no longer freezes while it waits.

What gets in the way
  • The window is called Manage Resources for Pre-Loading, while the menu that opens it says Pre-Load Resources.
  • The list is plain text: paths and links, with [Cubic Panorama] or [Slideshow] in front of the names. Nothing says what a file is, how big it is or what it looks like.
  • Three Add buttons sit in a column at the bottom right, and each one hides this window while its chooser is open.
  • Adding something that's already in the list does nothing, without a word.
  • Remove works on one resource at a time, asks every time, and can't be undone.
  • Nothing says whether a resource loaded. A deleted file, a typo in a link, a deleted panorama or a slow download only show up in the log.
  • A new resource only loads at the next game start or resource reload, and nothing says so.
  • Pre-loading waits for one resource after the other, up to 2 minutes each, on the game's main thread. The loading screen freezes while a slow download runs.
  • Nothing shows where a resource is used.
  • Cancel throws away every change without asking.

The window, piece by piece

The list
One row per resource: a thumbnail, or the kind's icon for sounds, the name, and the kind with its size, or from the web for links. On the right the time it took at the last game start, or the percentage while it loads. A problem replaces the size in amber or red, like didn't load in time or file not found. Ctrl and Shift select several.
Add Resource
A menu, searchable like every menu: File or Link opens the shared Choose Resource window for an image, sound, video or text, from the game folder, a resource pack or the web. Below it, every panorama and every slideshow FancyMenu loaded, the same ones Choose Panorama and Choose Slideshow list, sorted by name. Ones that are in the list already aren't shown, and a heading with nothing left under it disappears (rule 123).
The preview
The same stage as the AFMA Creator, on a checkerboard for transparency. Animations play their intro once, then loop. Panoramas pan around, slideshows fade from image to image like in a layout, videos wait on a poster frame with a play button. Sounds show a waveform: click it to jump there. A bar under it has play and pause and the details, like 1280 × 720 or 0:45 of 2:48, and the size.
Loading
While a resource loads or downloads, a card at the top shows the percentage, a bar, the time left and what it's at, like 896 KB of 1.4 MB or Image 4 of 6. Once it's done, the preview takes its place. How long it took at the last game start sits on its row in the list, and only problems get a card.
Problems
A card over the preview says what went wrong in plain words and offers the fix. A missing file gets Choose Another File, and says whether anything still uses it. A download that held the start up says that a copy in the game folder loads in a moment. Load Again in the header tries again.
Used in
Every layout, global customization and script that uses the resource, grouped by place like in Variables and Schedulers, each with Open. When nothing uses it, a line says that pre-loading it only makes the game start slower and takes memory.
Several selected
The number and their size together, and Load Again and Remove for all of them. Below, the selected rows with their times or problems.
The footer
How long the last game start waited for pre-loading, and for which resource when one held it up. After a change, what changed, with Undo. Cancel and Done on the right, like today: Done saves the list, Cancel puts it back.

Speed up, fix, clean up

A menu that pops in
1The multiplayer screen opens, and its Snowy Peaks background shows up a moment later.
2Add Resource lists every panorama that isn't pre-loaded yet. Pick Snowy Peaks.
3It shows up in the list and loads right away: Image 4 of 6, then the panorama pans around and its row says 1 s.
4Done. From the next game start on, the multiplayer screen opens with its background there.
A slow download
1The footer says the last game start waited 30 s for intro_cinematic.mp4, and its row says didn't load in time.
2The card says the server sends it slower than the game start waits, and that it popped in later.
3Put the video in the game folder and use it in the layout. Open under Used in jumps right to the Intro video element.
4Add the copy with File or Link and remove the link. It loads from the disk now, in a moment.
A file that's gone
1old_logo.png shows a broken image and file not found in red. Filter by With Problems to see all of them.
2The card says nothing uses it anymore, and Used in is empty.
3Press Delete. The footer says it won't load at the next game start, with Undo.
4Still used somewhere? Choose Another File points it to where the file is now.

Special cases it handles

  • Removing a resource doesn't unload it. Places that use it keep it until the game closes, and it just doesn't load at the next game start.
  • Cancel puts the list back. What was only loaded for this window gets released again, unless something on the screen uses it.
  • A download that isn't done has no thumbnail and no preview yet, only the kind's icon and the loading card. Removing it stops the download.
  • Panoramas and slideshows count their images while they load, since they're several files.
  • Resource reloads, like F3+T or turning on a resource pack, pre-load everything again, like today, and update the times.
  • The 30 seconds count for all resources together, since they load side by side, so ten slow ones can't add up to five minutes.
  • When the game start stops waiting, the resource keeps loading, and the menu that uses it shows it once it's there.
  • A sound played in the preview uses the Master channel at the game's volume, and stops when another resource gets selected or the window closes.
  • A panorama or slideshow deleted from its folder shows panorama not found or slideshow not found, like a missing file.

Changes beyond the UI

The window above already uses these. They change how pre-loading runs, saves and reports, so each one is a rework rule.

Pre-loading never freezes the game start New, rule 119
Today ResourcePreLoader.preLoadAll runs in FancyMenu's reload listener, on the main thread, and waits up to 120 s for each resource in turn. It becomes its own reload step: it starts every resource at once and hands Minecraft a future that completes when all of them are done, or after 30 s in all, so the loading screen keeps drawing.
Pre-loading reports what happened New, rule 120
Every entry keeps its last result: loaded, failed with a reason like file not found or panorama not found, or still loading when the start stopped waiting, plus how long it took and its size. The pre-loader times them itself, since it waits for them anyway, so nothing else gets timed.
Resources know where they're used New, rule 121
The index of rule 87 also collects resource sources: element settings that hold a file (rule 79), backgrounds, global customizations, and action values like Play Audio's, also from addons. Used in and the Unused note read it.
Pre-load changes take effect right away New, rule 122
Adding a resource loads it at once, Load Again releases it and loads it again, and Cancel releases what was only loaded for the window. The list itself still gets saved with Done, like today.
Add Resource lists what's left to add New, rule 123
The menu lists every panorama from config/fancymenu/panoramas and every slideshow from config/fancymenu/slideshows that FancyMenu loaded, by the name in its properties.txt and sorted by name, leaving out the ones in the list.
Rows show what their file is Covered, rule 22
Thumbnails, the kind's icon for sounds, and missing files in red with a broken image.
Cancel asks only when something changed Added to rule 68
Discard 2 changes? only shows when the list changed. Load Again and playing a preview don't count.
