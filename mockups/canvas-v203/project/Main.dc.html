FancyMenu · UI rework concept · issue #1838

Every option, visible before you click

Cycle buttons hide their choices behind repeated clicks. These controls show what you can pick right away, put each label on the same line as its control, and wrap every window in a macOS-style title bar.

Pick the right control

Three controls replace every cycle button. If all options fit on one line, show them all. If they don't, put them in a menu.

Segmented control

Works like tabs: the selection slides to the clicked segment, and a click mid-slide just redirects it, so nothing waits on the animation. Most need no label. The text under it explains the current choice, so you don't need a tooltip.

Pop-up menu

The chevron shows it opens. While open, it flips and the current value gets a checkmark. Short hints help with technical choices. The list is the same menu as everywhere else, so ↑ ↓ move through it and typing searches it. Long lists scroll with the same scroll bar as everything else.

Scroll bars

Everything that scrolls, menus included, shows the same scroll bar as long as there's more to see. It never hides until you scroll, so a list that goes on always looks like one. The thumb is round, at least 28 px long, and grows on hover so it's easy to grab.

Rows, switches and fields

Labels sit on the same line as their controls inside rounded groups, so a screen shows twice as much without scrolling. Short help text goes under the label instead of in a hidden tooltip. "Open in Editor" turns into an icon inside the field.

Window title bar

Window buttons move to the top left as colored dots. Their symbols only show while the pointer is over the group, and then all three show together. The title and its icon sit centered, and the title bar uses the window's own color instead of a gray strip.
