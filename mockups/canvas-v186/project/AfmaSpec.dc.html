FancyMenu · UI rework concept · AFMA Creator

See your animation before you create it

The AFMA Creator turns folders of PNG frames into one AFMA file. The window now plays the frames the way the file will play them, checks every frame before anything gets created, and puts today's 25 settings behind three quality choices, with the expert ones in plain words under Advanced. Creating shows real progress with the time left and ends with what it made, instead of a dialog with a path.

What gets in the way
  • Everything sits in one long scrolling panel: 3 paths, 3 timing fields, 6 cycle buttons and 9 number fields, most of them encoder internals with names like Max Axis Offsets or Perceptual Color Delta.
  • Nothing shows the frames. Whether they're the right ones, in the right order and at the right speed only shows once the export is done and the file is in a layout.
  • A frame with a different size only fails in the middle of the export, with an error message that holds the frame's full path.
  • The output path starts empty, so the first Export fails with Select a valid AFMA output path first. A file that already exists gets replaced without asking.
  • Dropped PNG files show up as Ordered PNG List (12 frames): frame_01.png in the path field.
  • Frame times only take milliseconds, so 24 frames a second has to be typed as 41.
  • The three Perceptual fields stay editable while Near-Lossless is off, even though the export ignores them then.
  • Switching the preset overwrites every value you changed, without a word.
  • Progress is a thin bar with texts like Analyzing AFMA frames for export..., and the result is a dialog with the path. Nothing says how long it takes or how big the file got.
  • Close and Esc stop a running export without asking, and every setting starts over the next time the screen opens.

The window, piece by piece

The preview
Plays the frames scaled to fit, with sharp pixels for pixel art, over a checkerboard for transparent frames. The intro plays once, then the main frames as often as Loops says, and Once stops on the last frame like the file does. A click on it plays or pauses. The tag in the corner says the part and the file, like Main, 2 of 3 · frame_0012.png, and turns red on a frame with a problem.
The timeline
One segment per part, as long as it plays, so a slow intro looks long. The played part is tinted and the playhead follows the preview. Dragging scrubs, the frame under the pointer shows as a thumbnail with its file name, and problems sit on it as red and amber marks. The time on the right counts from the start of the intro to the end of the main frames.
Frames
A row for the intro and one for the main frames: a stacked thumbnail, the folder's name, then the number of frames, how long they play and their size. Choose Another Folder and Remove sit on the right, and a part without frames shows Choose Folder instead. Problems show under the row in red or amber, each with Show. Before the main frames are added, the whole column is one drop area that says what to drop.
Playback
Speed in milliseconds a frame or frames a second, picked in the field's unit menu, with the other unit under the label. Intro speed only shows with an intro and stays empty to play at the main speed. Loops is Forever, Once or Several with a count, and says that the intro plays only once. The preview takes every change right away and stays on the frame it shows.
Quality
Best Quality keeps every pixel. Balanced lets colors shift a little where nobody notices and is the quickest. Smallest File allows a bit more shift and searches harder. Each one says that under the buttons, and the presets set the same values as today's, so a file made with Balanced comes out exactly as big.
Advanced
Closed by default. Four groups in plain words: full frames, moved areas, tiny color changes and repeated frames. A setting that only matters while another one is on only shows then. A changed value gets a blue bar on the left, its row shows a reset arrow on hover, and the header counts the changes and offers Reset to Balanced.
Save as
The name, with .afma after it, named after the main folder until you type something else, and the folder, config/fancymenu/assets unless Change picks another. A note says that layouts can use files in the assets folder right away, or that the file already exists and gets replaced. Check the file after saving is here too, off like today.
Creating
A card at the top of the right column: Creating dusk_valley.afma, the percentage, a bar, the frame it's on, like Analyzing main frame 20 of 72, and the time left. The preview shows that frame and the timeline fills up with what's done. Every setting stays readable but locked, and Stop takes the main button's place.
The footer
On the left, what will be made, like 108 frames at 1280 × 720, 4.4 s from start to end, or why Create AFMA is off, in red. After a change it says what changed, with Undo. On the right Close and Create AFMA, which turns into a red Replace when the file exists, and into Stop while it creates.

Special cases it handles

  • Minecraft only learns about dropped files when they're dropped, not while they're dragged, so the window can't light up a target. Where the pointer is at the drop decides instead: on the Intro row they become the intro, on the Main row the main frames, and anywhere else the main frames while there are none, then the intro, like today (rule 118).
  • Dropped PNG files instead of a folder show as 12 dropped files, with frame_01.png to frame_12.png under it, in file name order. A dropped .afma file becomes the file to save as.
  • An intro alone would play as the main animation, so Create AFMA needs main frames, and the Intro row stays optional.
  • Intro frames with another size than the main frames get the same red message on the Intro row, since one file has one size.
  • A gap in the numbering, like frame_0041.png followed by frame_0043.png, is only a warning. The frames still play in name order.
  • Color and Transparency are sliders from 0 to 255, because a channel can't shift further than that. Average stays a number field with a stepper: the encoder's value can reach 1275, since transparency counts double and the three colors once each, but useful values stay below 20, too small a part of a slider to hit.
  • The preview and the thumbnails use small copies, decoded in the background, so 300 frames at 4K scrub as smoothly as 30 small ones, and the window never waits for them.
  • Changing the speed, the intro speed or the loops keeps the frame that shows and plays on from there, so the preview never jumps or stops early.
  • Stop leaves an existing file untouched: the new file gets written next to it and only takes its place at the very end, like today.
  • When creating fails anyway, like when the disk is full, the card says so in plain words with Show Details for the full message, and the settings unlock again.
  • Closing the window while it creates asks first. Stop and Close saves nothing, and Keep Creating goes back.

Changes beyond the UI

The window above already uses these. They change how the creator reads frames, runs and reports, so each one is a rework rule.

The AFMA Creator checks frames before it starts New, rule 114
When frames are added, it reads every PNG's size from the start of the file, without decoding it, and the numbers in the names. Frames of another size, an intro that doesn't match the main frames and gaps in the numbering show on the rows, localized, instead of an exception halfway through the export.
The AFMA Creator previews frames New, rule 115
A background thread decodes the frames into small copies at the preview's size and keeps them in a cache. The preview plays them with the window's speed, intro and loops, the way AfmaTexture plays the file, and the thumbnails come from the same copies.
The AFMA Creator is a window that remembers New, rule 116
AfmaCreatorScreen becomes a window like the other tools, so the menu bar and the screen behind it stay usable. The job keeps going while the window is collapsed, and the frames, settings and file name come back the next time it opens.
The encoder reports progress and results as data New, rule 117
AfmaEncodeProgress carries English texts like Analyzing AFMA frames for export... today. It reports the phase, the part and the frame number instead, so the window can say Analyzing main frame 20 of 72 in every language, show that frame and estimate the time left. A finished job also returns the file's size and how many frames it stores in full.
Cycle buttons become controls Covered, rules 15 and 16
Optimization Preset becomes a segmented control, and the five Enabled and Disabled buttons become switches.
Replacing a file says so Added to rule 40
Create AFMA becomes a red Replace while the file under Save as exists.
