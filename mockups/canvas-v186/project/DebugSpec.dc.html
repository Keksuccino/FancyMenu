FancyMenu · UI rework concept · Debug Overlay

Numbers you can read at a glance

The Debug Overlay tells you what screen you're on, how much FancyMenu loaded and how the game runs. Its stack of black text lines becomes one tidy panel with sections that fold, small graphs next to their numbers, and a tag on whatever the pointer is over. It also costs less to draw.

What gets in the way
  • Every value is its own black bar, as wide as its text. Together they cover a ragged part of the screen you want to look at.
  • Labels are long, like Current Screen Enabled Layouts, and each one explains itself in brackets.
  • Four graphs take a full row each, twice as tall as a line of text.
  • Categories can only be turned off in a submenu of the menu bar.
  • Only vanilla widgets get an outline and a menu. The layout's own elements don't, though their IDs are needed just as often.
  • Nothing says what an outline belongs to until you right-click it.
  • Every line gets built and measured again in every frame. Memory and CPU are read twice a frame, once for the number and once for the graph, and the processor and graphics names are asked for again each time.
  • A graph takes one sample per frame, so how much time it shows depends on the frame rate.

The panel, piece by piece

The header
Debug, and three buttons: Copy Everything as Text, move to the other side, and Hide, which is the same as Ctrl+Alt+D.
Screen
The identifier with its copy icon, the size with the GUI scale, how many of the screen's layouts are on and how many of those are universal, and how many elements are active.
Resources
Slideshows with their images, panoramas, and how many pre-loaded resources loaded. A resource that didn't load in time turns the row amber.
System
FPS, memory and both CPU loads, each with a graph of the last 12 seconds, then the processor and the graphics card with its OpenGL version.
Folded sections
A folded section shows its most important value in its header, like 118 FPS, in amber or red when something in it is.
Outlines and the tag
Everything the layout shows gets a thin dashed outline. The one under the pointer gets a solid one and a tag with its name, type and ID. Vanilla widgets show their locator instead.

Special cases it handles

  • The panel keeps its side and which sections are folded, like the four category switches are kept today.
  • With the menu bar hidden, the panel moves up to the top edge.
  • Hidden vanilla widgets get no outline, like today.
  • The limits for amber and red stay: FPS under 20 and under 10, memory from 60 % and 80 %, CPU over 50 % and from 80 %.
  • The menu of a layout element has Copy Element ID and Edit in the Layout Editor. A vanilla widget also has Copy Widget Locator.
  • Edit in the Layout Editor opens the layout the element is from with it selected. For a vanilla widget it opens the screen's first layout that is on, or a new one.
  • Copy Everything as Text copies the rows as plain lines, with the current numbers and without the graphs.
  • The tag never covers the element: it sits above it, or below when there's no room.

Changes beyond the UI

The panel above already uses these, so each one is a rework rule.

The Debug Overlay is one panel New, rule 145
DebugOverlay draws a list of lines that each have their own position and background. It becomes one panel with sections, rows and graphs as data, and the four category options turn into the folded state of three sections.
The Debug Overlay samples on a clock New, rule 146
Values get read four times a second into one sample that the number and its graph share. Names that can't change, like the processor, get read once, and a row's text is only built again when its value changed.
The Debug Overlay outlines every element New, rule 147
renderWidgetOverlays only collects vanilla widgets. It collects the layout's own elements too, and the menu gets Edit in the Layout Editor.
Pre-loading reports what happened Covered, rule 120
The Pre-loaded row reads the results that rule 120 keeps.
Every menu is the same menu Covered, rule 27
An element's right-click menu is the shared menu.
