- ⚠️ [Item Display Incompatible with TACZ Weapon and Ammo Models](https://github.com/Keksuccino/FancyMenu/issues/1661)
  - ⚠️ Not applicable to Minecraft 26.2: TACZ's official source and latest release still target Forge 1.20.1 only, with an explicit Minecraft version range of 1.20–1.20.1 and no Fabric or NeoForge 26.2 port. In the reported 1.20.1 case, TACZ registers generic gun and ammo items and selects their concrete models from `GunId` and `AmmoId` NBT; FancyMenu's documented `slot_item` placeholder returns only the registry key, so using it as an Item element key creates a new stack without TACZ's required variant NBT and TACZ deliberately renders its missing-texture fallback. TACZ has not changed that model contract, and a FancyMenu compatibility layer cannot be implemented or tested against a nonexistent 26.2 TACZ API. A supported TACZ 26.2 port and current reproduction are required before compatibility work is possible; on 1.20.1, the Item element must be given the matching custom NBT instead of only the generic registry ID.
- ⚠️ [Black screen flicker with Alex's Caves holographic projector in 3.9.x (3.8.1 is fine)](https://github.com/Keksuccino/FancyMenu/issues/1634)
  - ⚠️ Not applicable to Minecraft 26.2: Alex's Caves 2.0.2 officially targets Forge 1.20.1 and NeoForge 1.21.1, and its official repository has no 26.2 branch or release. The reported 1.20.1 path uses Citadel's legacy post-effect registry to render the hologram into a custom target and composite it through `RenderTarget.blitToScreen(..., false)`; FancyMenu 3.9.x introduced a global hook for that legacy blit path and its `BlendMode` cache, which is absent from both FancyMenu 26.2 and Minecraft 26.2's frame-graph/render-pipeline post-processing path. Alex's Caves has not applied a corresponding 1.20.1 projector fix, but this obsolete rendering interaction cannot be safely implemented or tested on the current branch. An official Alex's Caves 26.2 port and a current reproduction are required before compatibility work is possible.
