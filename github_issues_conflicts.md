- [x] [Numismatic Overhaul tooltips break in Creative Inventory](https://github.com/Keksuccino/FancyMenu/issues/1257)
  - Fixed in FancyMenu: on Minecraft 1.21.1, Numismatic Overhaul 0.3.4 and 0.3.5 create the creative-inventory purse as an owo layer and register its live currency tooltip updater once from the layer initializer through `ScreenEvents.afterRender`. FancyMenu then forced a second creative-screen resize on its first render solely for its old menu-bar integration; Fabric API 0.104.0's Screen API 2.0.25 replaces every per-screen event instance before each resize, while owo 0.12.15.4 preserves the existing layer and only resizes it without rerunning the initializer. The purse therefore remained visible through owo's newly registered generic renderer but lost its tooltip updater. FancyMenu's menu bar now uses the independent global screen-overlay render and input lifecycle, so the obsolete forced resize has been removed. This also avoids an unnecessary full creative-screen rebuild on NeoForge. Sodium, Sodium Extra, and Iris do not modify creative-screen initialization or tooltip rendering.
